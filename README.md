# Test Data Generator

توليد بيانات اختبار وهمية قابلة لإعادة الإنتاج.

## التشغيل

### Python
```bash
python3 tool.py --help
```

### Termux
```bash
pkg update && pkg install python
python tool.py --help
```

### iSH
```sh
apk update && apk add python3
python3 tool.py --help
```

## مثال

```bash
python3 tool.py --help
```

هذه أداة دفاعية/تعليمية تعمل على بيانات محلية أو أهداف يملكها المستخدم. لا تستخدمها للوصول غير المصرح أو التجسس أو تجاوز الصلاحيات. لا توجد مكتبات خارجية مطلوبة.
